# 프로젝트: 스트라이크아웃 게임

## 목표
- 브라우저에서 실행되는 스트라이크아웃 숫자 게임을 만든다.

## 기능
- 시스템은 3자리의 히든 숫자를 제시한다.
- 사용자가 3자리의 숫자를 입력한다.
- 숫자와 자릿수가 모두 일치하면 스트라이크(STRIKE) 표기
- 숫자는 있는데 자릿수가 일치하지 않으면 볼(BALL) 표기
- 일치하는 숫자가 없으면 표기 없음
- 사용자가 입력한 숫자가 히든 숫자와 일치하면(3 STRIKE 이면) 성공
- 최대 20회까지 입력 가능하고 20회 동안 성공하지 못하면 실패

## 기술
- 순수 HTML, CSS, JavaScript를 사용한다.
- 하나의 `index.html` 파일, 하나의 `style.css` 파일로 구성한다.
- 별도의 빌드 도구나 서버 없이 브라우저에서 바로 실행 가능해야 한다.

## 대상
- 중급 개발자

