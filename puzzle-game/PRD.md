# 프로젝트: 간단한 퍼즐 게임

## 목표
- 브라우저에서 실행되는 웹 기반 퍼즐 게임을 만든다.

## 기능
- 퍼즐 보드를 표시한다.
- 사용자의 클릭 이벤트를 처리한다.
- 클리어 조건을 판단한다.
- 6x6 퍼즐 보드에서 동일한 과일 이미지 2개를 맞추는 게임으로 구현한다.

## 기술
- 순수 HTML, CSS, JavaScript를 사용한다.
- 하나의 `index.html` 파일, 하나의 `style.css` 파일로 구성한다.
- 별도의 빌드 도구나 서버 없이 브라우저에서 바로 실행 가능해야 한다.

## 대상
- 고급 개발자

## 폴더 구조
```text
puzzle-game/
├─ index.html
├─ css/
│  └─ styles.css
├─ js/
|  ├─ app.js    -- 기존 script.js에서 앱 시작점 관련 소스만 위치
|  ├─ board.js  -- 퍼즐보드 그리기 영역
|  ├─ game.js   -- 클릭이벤트, 정답확인, 클리어조건
│  └─ utils.js  -- 랜덤섞기, 공통함수
├─ assets/
│  └─ images/
└─ PRD.md
```
